# 哨笛指法生成器

一个本地运行的静态网页：输入简谱或字母音名，自动生成哨笛（六孔）指法，并支持打印。

## 使用

1. 直接用浏览器打开 `index.html`。
2. 在输入框中粘贴简谱或音名。
3. 选择调性与八度，点击“生成指法”。
4. 点击“打印”即可得到打印版。

## 输入格式

- 简谱：`1-7`，可用 `#`/`b` 表示升降，`'` 表示高八度，`.` 表示低八度。
- 字母音名：如 `D4`、`F#4`、`Bb3`。

## 自定义指法

指法表支持自定义，格式为 6 个字符：`X`=闭孔，`O`=开孔，`H`=半孔。修改后会保存在浏览器本地。

## 说明

默认指法以 D 调哨笛常见指法为起点，实际演奏可能存在指法差异，可自行调整表格。
